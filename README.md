### Python File Organizer (pyfiorg)

A simple script I made to organize my downloads folder.

### Installation
You can install it via pip:
`pip install python-file-organizer`

After that you should be able to run the `pyfiorg` command anywhere.
### Usage
`pyfiorg [DIRECTORY]`: Checks all of the files in the specified directory, creates folders for them and moves them there, any file with an extension that isn't listed will be moved to the `Others` folder.
`pyfiorg here`: Allows you to choose the active working directory as the place to organize instead.
